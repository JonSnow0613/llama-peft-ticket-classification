# Fine-tuning Time vs Performance: PEFT Methods on Llama 3.2 1B

Notebook experiment comparing customer-support intent classification methods on a 27-class task using the Bitext customer-support dataset.

## Methods in the notebook
- Zero-shot and few-shot inference
- LoRA and QLoRA (4-bit NF4 base model + LoRA)
- IA3
- Prompt tuning and prefix tuning
- MPNet full-fine-tuning baseline

The notebook includes preprocessing, a shared train/evaluation setup, timing/resource logging, and a results comparison. The notebook's own configuration controls smoke-test versus full runs; inspect `SMOKE_TEST` before starting a long run.

## Requirements and access
Recommended: a CUDA GPU with sufficient VRAM (the notebook was designed around a T4-class GPU), Python 3.10+, and current compatible versions of Transformers, PEFT, Accelerate, Datasets, and bitsandbytes.

```bash
pip install -U transformers peft bitsandbytes accelerate datasets pandas numpy scikit-learn matplotlib
```

The notebook downloads the dataset and model at runtime. Access to `meta-llama/Llama-3.2-1B-Instruct` may require accepting the model terms and authenticating with Hugging Face. Check the `MODEL_ID` and `DATASET_ID` variables in the configuration cell. If running on a hosted notebook, enable a GPU runtime.

## Run
1. Open `llama_peft_comparison.ipynb` in Kaggle or Google Colab with GPU enabled.
2. Review model/dataset access and the configuration cell.
3. Run a smoke test first; set `SMOKE_TEST=False` only when ready for the full experiment.
4. Run all cells and inspect the results table generated by the notebook.

## Reproducibility and interpretation
The notebook sets random seeds and uses a shared evaluation workflow, but exact results and run times depend on GPU, package versions, model access, and the run configuration. No benchmark numbers are asserted here because the uploaded notebook does not contain a completed results table in its saved outputs. Do not treat model scores as comparable unless the same data split and evaluation setup were used.
